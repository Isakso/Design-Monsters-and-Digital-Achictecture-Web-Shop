# Design Monsters & Digital Architecture – Web Shop

An older school project focused primarily on **software design, digital architecture, and architectural patterns**, using a clothes-on-demand webshop as the practical case.

## 🎓 About the Project

This project was developed as part of my software development studies.

The main focus was not simply building a webshop, but understanding how a larger software system can be **designed, structured, and architected**.

The project explored concepts such as:

* Software architecture
* System design
* Architectural patterns
* Separation of responsibilities
* Backend architecture
* Digital architecture
* Design decisions and trade-offs
* Structuring a web-based system

The **clothes-on-demand webshop** was used as the domain through which these architectural concepts were explored.

## 🏗️ Architecture & Design

A key part of the project was examining how different parts of a digital system can be organized and how the different components interact with each other.

The project focused on questions such as:

* How should the system be structured?
* How should responsibilities be separated?
* How should different components communicate?
* How can an architecture be made easier to maintain and extend?
* Which architectural and design patterns are appropriate for different problems?

## 🛍️ Web Shop Domain

The webshop provided a practical domain for applying the architectural concepts.

The system was based around a **clothes-on-demand business**, providing a realistic scenario for considering products, customers, orders, and other webshop-related functionality.
